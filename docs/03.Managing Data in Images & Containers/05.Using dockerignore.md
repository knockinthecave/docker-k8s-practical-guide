# .dockerignore 사용하기

> `COPY` 명령으로 이미지에 복사되면 안 되는 파일·폴더를 `.dockerignore`로 제외하는 방법을 다룬다.

## .dockerignore란?

프로젝트 폴더(빌드 컨텍스트 루트)에 `.dockerignore` 파일을 추가하면, 이미지에 **복사하지 않을 파일과 폴더**를 지정할 수 있다.

- `COPY`로 복사할 때 `.dockerignore`에 적힌 파일·폴더는 **이미지 내부로 복사되지 않는다.**
- `.gitignore`와 같은 방식으로, 한 줄에 하나씩 경로를 적는다.

## 왜 필요할까?

`COPY . .`처럼 폴더 전체를 복사하면 이미지에 불필요하거나 위험한 파일까지 들어간다.

- `.git`: 커밋 이력 전체가 들어가 이미지 크기가 커진다.
- `.venv`, `__pycache__`: 로컬 환경에서 만든 파일이라 컨테이너에서 쓸모가 없다.
- `.env`: 비밀 값이 이미지에 박혀 유출될 수 있다.
- `docs`, `README.md`: 실행에 필요 없다.

제외하면 **빌드 컨텍스트 전송량이 줄어** 빌드도 빨라진다.

## 이 프로젝트의 .dockerignore

```
.git
.gitignore

# 가상환경·캐시
.venv
__pycache__
*.pyc
.mypy_cache
.ruff_cache
.pytest_cache

# 이미지에 불필요한 파일
docs
README.md
LICENSE
Dockerfile
.dockerignore

# 로컬 런타임 데이터 (컨테이너가 /app/tmp, /app/data를 직접 생성)
tmp
data

# 비밀 값
.env
.env.*
```

- `main.py`, `requirements.txt`, `seed/`는 Dockerfile이 `COPY`하므로 **제외하면 안 된다.**
- `Dockerfile`과 `.dockerignore` 자체를 제외해도, `docker build`는 두 파일을 읽으므로 빌드에 영향이 없다.
- 이 프로젝트는 필요한 파일만 골라서 `COPY`하므로 안 넣어도 이미지에 들어가진 않는다. 다만 나중에 `COPY . .`로 바꿔도 안전하도록 미리 넣어 둔다.
