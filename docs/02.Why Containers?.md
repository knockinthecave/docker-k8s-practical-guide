# 컨테이너가 필요한 이유

독립적이고 표준화된 애플리케이션 패키지가 왜 필요할까?

## 1. 개발 환경과 운영 환경의 차이

- 로컬 머신에는 최신 NodeJS가 설치되어 있는데, 배포할 서버에는 이전 버전이 있을 수 있다.
- 이 경우 호환성이 깨져서, 로컬에서 잘 되던 코드가 서버에서는 동작하지 않는다.
- 앱에 필요한 버전을 컨테이너에 명시하면 **개발 환경과 운영 환경을 동일하게 고정**할 수 있다.

## 2. 팀·회사 간 환경 차이

- 팀원이나 회사마다 개발 환경이 다를 수 있다.
- 복잡한 의존성은 설치와 관리가 어려워 협업을 힘들게 하고, 모두에게 동일하게 동작한다는 보장도 없다.
- 소프트웨어 개발에서 호환성은 매우 중요하며, **모든 것이 포함된 환경을 갖는 것 자체가 가치**다.

## 3. 혼자 일할 때도 유용하다

- 프로젝트가 여러 개일 때 서로 다른 버전 때문에 생기는 충돌을 막을 수 있다.
- 프로젝트를 전환할 때마다 환경을 다시 맞추는 수고가 든다.
- 프로젝트별로 필요한 버전을 각자의 컨테이너에 담아 두면 **전환이 쉬워진다**.
