# 이미지(Image) vs 컨테이너(Container)

> 도커의 **핵심 기본 개념**이다. 이미지를 기반으로 컨테이너를 실행한다.

## 이미지

- 컨테이너를 만들기 위한 **템플릿**이자 **설계도(블루프린트)** 다.
- 코드와, 코드를 실행하는 데 필요한 **도구**, 그리고 **모든 설정 명령**이 포함된 **공유 가능한 패키지**다.
- **한 번만 정의하면** 다른 서버, 다른 시스템 어디에나 똑같이 적용할 수 있다.

## 컨테이너

- 이미지의 **구체적인 실행 인스턴스**다.
- 이미지를 바탕으로 만들어지고, 그 상태로 실행된다.

## 관계

```
이미지 (템플릿) ──┬──▶ 컨테이너 A
                  ├──▶ 컨테이너 B
                  └──▶ 컨테이너 C
```

- 하나의 이미지로 **여러 개의 컨테이너**를 만들 수 있다.
- 같은 이미지에서 시작하므로 모든 컨테이너가 동일한 환경으로 실행된다.

| 구분 | 이미지 | 컨테이너 |
|------|--------|----------|
| 역할 | 템플릿, 설계도 | 실행 중인 인스턴스 |
| 내용 | 코드 + 실행 도구 + 설정 명령 | 이미지를 기반으로 실행된 결과 |
| 개수 | 하나 | 하나의 이미지로 여러 개 |
