# 컨테이너 중지와 재시작

> 중지된 컨테이너는 `docker run`으로 새로 만들 필요 없이 `docker start`로 **다시 시작**할 수 있다. `run`과 `start`는 기본 동작 모드가 다르다.

> **Hint**: `docker --help`로 사용 가능한 다양한 명령어를 확인할 수 있다.

## 컨테이너 목록 조회

| 명령 | 설명 |
|------|------|
| `docker ps` | **실행 중인** 컨테이너만 조회한다. |
| `docker ps -a` | 중지된 컨테이너까지 **모두** 조회한다. |

```bash
docker ps        # 실행 중인 컨테이너
docker ps -a     # 중지된 컨테이너 포함 전체
```

## 중지된 컨테이너 다시 시작하기

컨테이너를 매번 `docker run`으로 실행할 필요는 없다.

- `docker run`은 실행할 때마다 **새 컨테이너를 만든다.**
- 이미 만들어 둔 컨테이너가 있다면 `docker start`로 **그 컨테이너를 다시 시작**하면 된다.
- 상황에 따라 새로 만들기보다 기존 컨테이너를 다시 쓰는 편이 나을 때가 있다.

```bash
docker stop <컨테이너 이름 또는 ID>     # 실행 중인 컨테이너 중지
docker start <컨테이너 이름 또는 ID>    # 중지된 컨테이너 다시 시작
```

| 명령 | 설명 |
|------|------|
| `docker start` | 중지된 **기존 컨테이너**를 다시 시작한다. |
| `docker stop` | 실행 중인 컨테이너를 중지한다. |

```
docker run   ──▶ 새 컨테이너 생성 + 실행
docker stop  ──▶ 컨테이너 중지 (컨테이너는 남아 있음)
docker start ──▶ 같은 컨테이너 다시 실행
```

## run vs start: attached와 detached

컨테이너는 두 가지 모드로 실행할 수 있다.

| 모드 | 설명 |
|------|------|
| **attached** (포그라운드) | 터미널이 컨테이너와 **연결**되어 출력이 터미널에 표시된다. |
| **detached** (백그라운드) | 터미널과 **분리**되어 백그라운드에서 실행된다. |

| 명령 | 기본 모드 | 모드 바꾸기 |
|------|-----------|-------------|
| `docker run` | **attached** | `-d` 옵션으로 detached 실행 |
| `docker start` | **detached** | `-a` 옵션으로 attached 실행 |

```bash
docker run <이미지>          # attached: 콘솔 출력이 터미널에 보인다
docker run -d <이미지>       # detached: 백그라운드 실행

docker start <컨테이너>      # detached (기본)
docker start -a <컨테이너>   # attached: 출력을 터미널에서 확인
```

- **attached**일 때는 터미널이 실행 중인 컨테이너와 연결되어 있으므로 **콘솔 출력을 바로 볼 수 있다.**
- **detached**일 때는 터미널을 계속 쓸 수 있지만 출력이 보이지 않는다. 이미 백그라운드에서 돌고 있는 컨테이너의 출력은 아래 명령으로 확인한다.

```bash
docker logs <컨테이너>            # 지금까지의 출력 보기
docker logs -f <컨테이너>         # 실시간으로 계속 보기
docker attach <컨테이너>          # 실행 중인 컨테이너에 다시 연결
```

> 의도에 맞게 쓰면 된다. 출력을 보며 확인하고 싶으면 **attached**, 서버처럼 계속 띄워 두려면 **detached**를 쓴다.

## 정리

| 상황 | 사용할 명령 |
|------|-------------|
| 실행 중인 컨테이너 확인 | `docker ps` |
| 중지된 것까지 전체 확인 | `docker ps -a` |
| 새 컨테이너 만들어 실행 | `docker run` |
| 기존 컨테이너 중지 | `docker stop` |
| 기존 컨테이너 다시 시작 | `docker start` |
| 출력 보며 실행 | `docker run` / `docker start -a` |
| 백그라운드로 실행 | `docker run -d` / `docker start` |
