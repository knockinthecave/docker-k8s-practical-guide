# 이미지와 컨테이너 이름 · 태그 지정

> 이미지와 컨테이너는 **이름을 지정**할 수 있다. 이름을 알고 있으면 매번 `docker ps`, `docker images`로 ID를 조회하지 않아도 된다. 이미지는 여기에 **태그(버전)** 까지 붙일 수 있다.

## 컨테이너 이름 지정: --name

```bash
docker run -p 80:8000 -d --rm --name docker-practice-fastapi-app <IMAGE ID>
```

- `--name <이름>`으로 컨테이너에 원하는 이름을 붙인다. (지정하지 않으면 `kind_babbage` 같은 임의의 이름이 붙는다.)
- 이름을 알고 있으므로 `docker stop docker-practice-fastapi-app`처럼 **목록을 조회하지 않고** 바로 다룰 수 있다.

## 이미지 이름과 태그

이미지 태그는 **이름(리포지토리)** 과 **태그**, 두 부분으로 구성되며 콜론(`:`)으로 구분한다.

```
이름:태그
node:20.12.1
fastapi:latest
```

| 부분 | 설명 | 예 |
|------|------|----|
| 이름 (리포지토리) | 이미지의 **일반적인 그룹 이름** | `node`, `fastapi` |
| 태그 | **특정 버전**을 가리키는 선택 항목 | `14`, `20.12.1`, `latest` |

- 태그는 **옵션**이다. 이름만 쓰면 기본값(`latest`)이 사용된다.
- `node`는 일반적인 이미지 그룹이고, 태그에 **특정화된 버전**이 붙는다고 보면 된다.
- 베이스 이미지를 고를 때도 이 태그로 **적합한 버전**을 선택한다. (예: `FROM node:20.12.1`)

## 내 이미지에 이름과 태그 지정: -t

```bash
docker build -t "fastapi:latest" .
```

- 이름과 태그 모두 **자유롭게 커스텀**할 수 있다.
- 이름과 태그를 결합하면 **특정 버전을 가진 이미지**를 만들 수 있다.

## 태그로 컨테이너 실행

이미지 ID 대신 `이름:태그`를 그대로 쓸 수 있다.

```bash
docker run -p 80:8000 -d --rm --name docker-practice-fastapi-app fastapi:latest
```

## 정리

| 대상 | 옵션 | 예 |
|------|------|----|
| 컨테이너 이름 | `docker run --name <이름>` | `--name docker-practice-fastapi-app` |
| 이미지 이름:태그 | `docker build -t <이름>:<태그>` | `-t fastapi:latest` |

> 태그를 통해 같은 이미지의 **다양한 버전**을 구분해서 사용할 수 있다.
