# 이미지와 컨테이너 제거

> 컨테이너는 `docker rm`, 이미지는 `docker rmi`로 제거한다. **컨테이너를 먼저 지워야** 그 컨테이너가 쓰던 이미지를 지울 수 있다.

## 컨테이너 제거: docker rm

| 명령 | 설명 |
|------|------|
| `docker rm <컨테이너>` | **중지된** 컨테이너를 제거한다. |
| `docker rm <컨테이너1> <컨테이너2> ...` | 여러 컨테이너를 한 번에 제거한다. |

```bash
docker stop <컨테이너>   # 1. 먼저 중지
docker rm <컨테이너>     # 2. 그 다음 제거
```

- **실행 중인 컨테이너는 `docker rm`으로 제거할 수 없다.** 먼저 중지해야 한다.
- 컨테이너가 많으면 이름을 하나씩 `docker rm`에 넣는 것은 번거롭다. (수동 작업)

## 이미지 확인: docker images

```bash
docker images
```

- 내가 가진 **모든 이미지**가 표시된다.
- `Dockerfile`로 직접 만든 이미지도 함께 보인다.
- 직접 만든 이미지는 **베이스 이미지 위에 용량이 더해진** 크기로 표시된다. 이미지는 기본적으로 **다른 이미지를 기반으로 쌓아 올려 만들기** 때문이다.

> 이름(태그) 없이 빌드한 이미지는 `<none>` / `<untagged>`로 보인다. 빌드할 때 `-t <이름>`을 붙이면 구분하기 쉽다.

## 이미지 제거: docker rmi

필요한 이미지와 불필요한 이미지가 섞여 쌓였다면 `docker rmi`로 정리한다.

| 명령 | 대상 |
|------|------|
| `docker rm` | **컨테이너** 제거 |
| `docker rmi` | **이미지** 제거 (`rm` + `image`) |

```bash
docker rmi <이미지 이름 또는 ID>
docker rmi <이미지1> <이미지2>     # 선택해서 여러 개 제거
```

- 이미지를 제거하면 **그 이미지의 레이어가 삭제**된다. (다른 이미지가 공유하는 레이어는 유지된다.)
- `docker rmi`로 **원하는 이미지만 선택**해서 지울 수 있다.

### 제거 순서가 중요하다

이미지는 **더 이상 사용되지 않을 때만** 제거할 수 있다.

- **중지된 컨테이너가 남아 있어도** 그 이미지는 "사용 중"으로 취급되어 제거할 수 없다.
- 그러므로 항상 **컨테이너 제거 → 이미지 제거** 순서로 진행한다.

```bash
docker ps -a               # 이미지를 쓰는 컨테이너 확인
docker rm <컨테이너>        # 1. 컨테이너 제거
docker rmi <이미지>         # 2. 이미지 제거
```

## 중지 시 컨테이너 자동 제거: --rm

`--rm` 플래그를 주면 컨테이너가 **종료될 때 자동으로 제거**된다.

```bash
docker run -p 3000:80 -d --rm <이미지ID>
```

- 중지된 컨테이너를 **매번 직접 지울 필요가 없다.**
- 위 명령은 `-d` 옵션 때문에 **detached(백그라운드)** 로 실행된다.
- `docker stop`으로 중지하면 컨테이너가 **자동으로 삭제**된다. (`docker ps -a`에도 남지 않는다.)
- `--rm`은 **컨테이너만** 지운다. **이미지는 그대로 남는다.**

| 플래그 | 효과 |
|--------|------|
| `-d` | 백그라운드(detached)로 실행 |
| `--rm` | 컨테이너 종료 시 자동 제거 |

## 정리

| 하고 싶은 일 | 명령 |
|--------------|------|
| 컨테이너 제거 | `docker rm <컨테이너>` (중지 후) |
| 이미지 목록 보기 | `docker images` |
| 이미지 제거 | `docker rmi <이미지>` (컨테이너 먼저 제거) |
| 종료 시 컨테이너 자동 제거 | `docker run --rm ...` |
